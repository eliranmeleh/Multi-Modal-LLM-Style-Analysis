# Function-word list, version 1.

# The style distance is computed over the ordered sequence of these words and nothing else, so this
# file is part of the measurement instrument. It is VERSIONED, never edited in place: changing an
# entry changes every delta ever computed, so a change means a new file (en_core_v2.txt) and a new
# manifest entry. See docs/DATA.md section 5.
#
# The list deliberately mixes modern and Early Modern English forms, so that no prior knowledge of
# any particular author's usage is encoded in the metric itself. A method that only counted modern
# forms would measure archaism rather than authorship.

#     9  relative and demonstrative
#    13  be, have, do
#     9  modals
#    13  verb forms, Early Modern
#    22  prepositions
#    12  conjunctions
#     8  negation and adverbials
#     9  quantifiers and determiners
